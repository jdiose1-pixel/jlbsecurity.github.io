JLB SECURITY — WEBSITE

1. Instalação local:
   - Coloque a pasta JLB_Security_Website no computador.
   - Abra o index.html para testar o site.

2. Para hospedar no próprio computador:
   - Instale Python 3.
   - Abra o CMD dentro desta pasta.
   - Execute:
       python -m http.server 8080 --bind 0.0.0.0
   - No próprio PC, abra:
       http://localhost:8080

3. Para acesso dentro da mesma rede:
       http://IP-DO-COMPUTADOR:8080

4. Para colocar na Internet:
   - Será necessário configurar o router para encaminhar a porta para o PC (port forwarding), além de firewall e, de preferência, HTTPS.
   - Se o seu ISP usar CGNAT, o acesso direto por port forwarding pode não funcionar. Nesse caso, pode-se usar um túnel seguro ou VPS.
